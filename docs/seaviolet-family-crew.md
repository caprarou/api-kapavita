# Liakos εν πλω · SEAVIOLET

Η οικογένεια και το πλήρωμα εναλλάσσονται **στην ίδια συσκευή**. Η οικογενειακή προβολή δείχνει πρώτα στοιχεία πλοίου και τελευταίο επαληθευμένο στίγμα στον χάρτη, κατόπιν τον προσωπικό χαιρετισμό. Οι χαιρετισμοί ζουν μόνο στη μνήμη της τρέχουσας συνεδρίας browser: δεν αποστέλλονται, δεν αποθηκεύονται στον server και χάνονται με ανανέωση σελίδας.

## Ταυτότητα και πηγή

SEAVIOLET · δεξαμενόπλοιο αργού πετρελαίου · IMO 9790983 · MMSI 248554000 · διακριτικό 9HA4701 · σημαία Μάλτας · κατασκευή 2018. Σταθερά στοιχεία: [VesselFinder](https://www.vesselfinder.com/vessels/details/9790983). Η εξωτερική καρτέλα μπορεί να δείχνει πληροφορίες που δεν έχουν αδειοδοτηθεί για ενσωμάτωση: το δικό μας UI δεν τις αντιγράφει ως ζωντανό AIS.

Η συλλογή στο `app/collect-seaviolet-ais.mjs` απαιτεί server-side `AISSTREAM_API_KEY` από [AISStream.io](https://aisstream.io/documentation). Εκτέλεση: `cd app && AISSTREAM_API_KEY=... node collect-seaviolet-ais.mjs` σε υπηρεσία παρασκηνίου. Το κλειδί παραμένει σε περιβάλλον του server. Το script φιλτράρει MMSI, ελέγχει θέση και γράφει ατομικά `app/dist/data/seaviolet-last-position.json`. Δεν υπάρχει ιστορική αναδρομή: η πρώτη θέση εμφανίζεται όταν παραληφθεί πραγματικό μήνυμα. Καταγράφεται ώρα παραλαβής AIS, όχι πλαστή ώρα εκπομπής. Ο server ανανεώνει το αρχείο χωρίς rebuild και ο browser ελέγχει ανά λεπτό. Το αρχείο θέσης μπορεί να χαθεί σε rebuild μέχρι να έρθει επόμενο μήνυμα. Χωρίς κλειδί ή παραληφθέν στίγμα ο χάρτης μένει κενός από δείκτη. Εξωτερικός σύνδεσμος παραπέμπει στο live tracker.

## Ώρες και ιδιωτικότητα

Η ημερομηνία και ώρα κάθε χαιρετισμού παρουσιάζονται ως ημέρα, μήνας, έτος και ώρα Ελλάδας (`Europe/Athens`), ανεξάρτητα από την ώρα στίγματος. Η ώρα του πλοίου προκύπτει από **χειροκίνητα επιλεγμένη ζώνη UTC του πληρώματος**, αποθηκευμένη μόνο στον ίδιο browser, με διαφορά από την τρέχουσα ώρα Ελλάδας και θερινή ώρα. Χωρίς τέτοια επιλογή αναγράφεται ανεπιβεβαίωτη. Η γεωγραφική θέση από μόνη της δεν πιστοποιεί τη ζώνη ώρας που χρησιμοποιεί το πλήρωμα.

Προεπιλογή προσωπικού χαιρετισμού: **χωρίς κοινοποίηση περιοχής**. Υπάρχουν επιλογές γενικής θάλασσας, ενώ πρόσφατο στίγμα μπορεί να προτείνει ευρεία περιοχή με ρητό πάτημα του χρήστη. Η επιλογή περιοχής στον χαιρετισμό δεν αλλάζει το AIS ούτε ισχυρίζεται ότι περιγράφει την τωρινή θέση. Ο χάρτης δηλώνει πηγή, ώρα και αν το στίγμα είναι παλιότερο από 24 ώρες. Προορισμός και ETA παραμένουν μη διαθέσιμα μέχρι να έρθουν από επιβεβαιωμένη κατάλληλη ροή.

## Επόμενο βήμα ενεργοποίησης

Εγκατάσταση server-side AISStream API key και εκκίνηση μόνιμης υπηρεσίας συλλογής. Η προσωπική επικοινωνία παραμένει τοπική όπως ζητήθηκε. Η δημόσια προβολή του στίγματος απαιτεί να επιβεβαιωθούν τα δικαιώματα επαναχρησιμοποίησης της επιλεγμένης ροής πριν ενεργοποιηθεί η υπηρεσία συλλογής.

## Ενεργοποίηση με κλειδί χρήστη

1. Δημιούργησε κλειδί στον δικό σου λογαριασμό [AISStream](https://aisstream.io/account) (η σύνδεση GitHub για εξουσιοδότηση λογαριασμού δεν ισοδυναμεί με δημιουργία κλειδιού).
2. Στο SSH/MobaXterm του VPS ως `dev`, εκτέλεσε `bash /home/dev/projects/kapavita/scripts/setup-ais.sh`. Θα ζητήσει κλειδί με κρυφή πληκτρολόγηση και, αν ζητηθεί, τον δικό σου κωδικό sudo. Το κλειδί γράφεται μόνο στο `/home/dev/.config/kapavita-ais/ais.env` με άδεια 600· δεν μπαίνει στο GitHub ή στο chat.
3. Έλεγξε `sudo journalctl -u kapavita-ais -n 25 --no-pager` για «AIS subscription confirmed» και, μετά το πρώτο σήμα, για «Received SEAVIOLET position». Για επισκόπηση δημοσιευμένης θέσης `curl -I https://api.kapavita.gr/data/seaviolet-last-position.json`· 404 σημαίνει ότι ακόμη δεν παραλήφθηκε μήνυμα.
4. Σε επανεκκίνηση ο systemd collector ξεκινά αυτόματα. Προτού ενεργοποιηθεί σε δημόσιο site, έλεγξε τους όρους χρήσης και προβολής της υπηρεσίας που εκδίδει το κλειδί.
