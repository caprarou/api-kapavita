# KapaVita Control · διαχειριστικό περιβάλλον

## Τι λειτουργεί

Η καρτέλα «Διαχείριση» επιτρέπει σε διαχειριστή να ενεργοποιεί/απενεργοποιεί τα δημόσια επίπεδα (περιφέρειες, δήμους, κοινότητες, πληθυσμό, αεροσκάφη, αεροδρόμια, καιρό, ποιότητα αέρα, θαλάσσιες περιοχές, κατάλογο). Το SEAVIOLET είναι **κλειστό δημόσια από προεπιλογή**. Ο διαχειριστής βλέπει VPS disk/memory, τρέχουσα κατάσταση Docker (στο VPS: μη εγκατεστημένο), βάση SQLite, διαθεσιμότητα αρχείου AIS και audit ενεργειών. Δημιουργεί λογαριασμούς admin/editor/viewer με ξεχωριστή παραχώρηση `seaviolet:view`, αλλάζει/ανακαλεί ενεργούς χρήστες. Ο ρόλος editor είναι θέση για μελλοντική επιμέλεια πηγών· ακόμη δεν έχει write endpoints περιεχομένου.

Στατιστικά: ενεργοί/σύνολο λογαριασμών, ρόλοι, ενεργές συνεδρίες, νέοι λογαριασμοί 30ημέρου, συνδέσεις 7ημέρου, συνολικές προβολές ανά ημέρα τελευταίας εβδομάδας και προβολές ανά ενότητα. Το `POST /api/visit` αυξάνει μόνο καθημερινό μετρητή ανά ενότητα στην ώρα Ελλάδας. Δεν αποθηκεύει ταυτότητα/IP διαδρομής επισκέπτη και **δεν μετρά μοναδικούς επισκέπτες**. Ανώνυμες προβολές μπορούν να περιλαμβάνουν ανανεώσεις σελίδας και automation.

Η βάση σήμερα είναι SQLite έξω από τον ιστότοπο στο `/home/dev/.local/share/kapavita/admin.sqlite3`. Η PostgreSQL/PostGIS με Docker **δεν είναι εγκατεστημένη**. Το dashboard το εμφανίζει ρητά. Πριν τη μεταφορά χρειάζονται backup/migration και διατήρηση user IDs, grants, feature flags και audit.

## Ασφάλεια

Η υπηρεσία ακούει μόνο `127.0.0.1:8787`. Ο Caddy προωθεί `/api/*`, αποκλείει άμεση πρόσβαση στο `/data/seaviolet-last-position.json` και εξυπηρετεί το SPA. Το endpoint `/api/v1/vessel/seaviolet` επιβάλλει άδεια `seaviolet:view` ή admin, εκτός αν ο διαχειριστής ενεργοποιήσει δημόσια προβολή. Ο κωδικός είναι scrypt με μοναδικό salt. Οι συνεδρίες είναι 8ωρες, secure HttpOnly SameSite Strict, και οι μεταβολές χρειάζονται CSRF token. Δεν υπάρχει κρυφός default admin ή συνθηματικό στο Git. Η δημόσια εναλλαγή γεωγραφικών επιπέδων ελέγχει την UI προβολή και αναζήτηση: τα δημόσια αρχεία ορίων παραμένουν προσβάσιμα ως open data, όχι ως προσωπικά αρχεία.

Το τελευταίο AIS γράφεται επίσης σε μη δημόσιο cache `/home/dev/.local/share/kapavita/seaviolet-last-position.json` και επανέρχεται μετά από Vite build. Η υπηρεσία AIS τρέχει με περιορισμένα δικαιώματα στο σύστημα. Το αρχείο θέσης προβάλλεται μόνο μέσα από το ελεγχόμενο API.

## Ενεργοποίηση VPS

Έχουν ετοιμαστεί το `Caddyfile.admin`, τα `scripts/kapavita-admin.service` και `scripts/setup-admin.sh`. Η εντολή εγκατάστασης **πρέπει να εκτελεστεί από τον χρήστη στο SSH**, επειδή αλλάζει Caddy και systemd με sudo:

```bash
bash /home/dev/projects/kapavita/scripts/setup-admin.sh
python3 /home/dev/projects/kapavita/scripts/admin_api.py bootstrap
```

Το bootstrap ζητά όνομα admin και δικό σου κωδικό δύο φορές με κρυφή εισαγωγή. Η εγκατάσταση κάνει backup του αρχικού Caddyfile, επαληθεύει hash για να μη σβήσει μεταγενέστερες αλλαγές σε άλλα sites, ελέγχει τη νέα ρύθμιση και επιστρέφει στον προηγούμενο Caddyfile σε αποτυχία. Μετά άνοιξε [api.kapavita.gr](https://api.kapavita.gr/) → Διαχείριση. Έλεγξε `curl https://api.kapavita.gr/api/public` (JSON) και `curl -I https://api.kapavita.gr/data/seaviolet-last-position.json` (404).

## Εκκρεμότητες

Η ανοιχτή πρόσβαση στα αρχεία δημόσιων γεωγραφικών συνόλων δεν μετατρέπεται σε granular dataset ACL. Χρειάζονται διακριτές άδειες προτού προστεθούν προστατευμένα datasets. Προγραμματισμένα jobs/notifications, Postgres metrics, backup/restore UI, ανεξάρτητες ροές οικογενειακών check-ins και προσαρμοσμένα δικαιώματα ανά dataset είναι μελλοντικά. Το UI δεν ισχυρίζεται ότι ήδη λειτουργούν.
