# Βάση δεδομένων KapaVita

Η PostgreSQL/PostGIS είναι η κύρια βάση για τον κατάλογο, τις γεωμετρίες και το ιστορικό
μετρήσεων. Η υπάρχουσα SQLite παραμένει προσωρινά μόνο για λογαριασμούς, συνεδρίες,
ρυθμίσεις και audit, ώστε η μετάβαση των δεδομένων να μην επηρεάσει τη σύνδεση διαχειριστή.

## Τι αποθηκεύεται

- `catalog`: οι πηγές, τα σύνολα, οι άδειες, η κάλυψη και η κατάσταση ελέγχου.
- `geo`: εκδόσεις διοικητικών και θαλάσσιων περιοχών με PostGIS γεωμετρία.
- `observations`: σταθμοί/μετρήσεις αέρα και ιστορικό θέσεων πλοίων.
- `pipeline`: κάθε εισαγωγή δεδομένων, το αποτέλεσμα και το πλήθος εγγραφών.

Τα πρωτότυπα στατικά αρχεία παραμένουν versioned artifacts. Η βάση περιέχει την ελεγμένη,
κανονικοποιημένη έκδοση που χρησιμοποιούν τα API. Ο browser δεν θα κατεβάζει ολόκληρη τη
χώρα όταν χρειάζεται μόνο την τρέχουσα περιοχή ή zoom· το επόμενο στάδιο είναι endpoint για
χωρικό υποσύνολο ή vector tiles.

## Εγκατάσταση

Το `scripts/setup-database.sh` εγκαθιστά PostgreSQL/PostGIS, δημιουργεί την τοπική βάση
`kapavita`, εφαρμόζει το migration και συγχρονίζει τον JSON κατάλογο. Η τοπική σύνδεση
χρησιμοποιεί peer authentication για τον χρήστη υπηρεσίας `dev`, χωρίς password σε αρχεία.

Τα migrations είναι επαναλήψιμα. Η εφαρμογή δεν πρέπει να γράφει απευθείας στους πίνακες
καταλόγου· οι αλλαγές συνεχίζουν να ελέγχονται στο Git και συγχρονίζονται στη βάση.
