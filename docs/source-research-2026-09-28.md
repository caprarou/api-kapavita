## Τι θα υλοποιήσουμε πρώτο

1. Ο χάρτης θα παίρνει τα διοικητικά επίπεδα από το PostGIS endpoint με bbox, αντί για στατικό GeoJSON.
2. Θα προστεθούν ως επόμενα ασφαλή layers οι σεισμοί USGS, η ποιότητα αέρα OpenAQ και οι καταγραφές GBIF.
3. Τα datasets με key ή περιορισμένη άδεια θα μείνουν ως καταγεγραμμένες πηγές μέχρι να επιβεβαιωθεί νόμιμη πρόσβαση.

Οι τεχνικές δυνατότητες επιβεβαιώθηκαν από τις επίσημες τεκμηριώσεις: το USGS δίνει παραμετρικό query σε GeoJSON, το GBIF παρέχει Occurrence API, το OpenAQ δίνει μετρήσεις και γεωχωρικά queries, ενώ το Eurostat διαθέτει SDMX API και πίνακες πληθυσμού NUTS3.
