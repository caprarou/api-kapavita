# SEAVIOLET · Έλεγχος εναλλακτικών AIS, 28/09/2026

Ταυτότητα στόχου: IMO 9790983, MMSI 248554000. Κριτήριο: πρόσφατο τεκμηριωμένο στίγμα και δικαίωμα εμφάνισης θέσης/προορισμού/ETA στην εφαρμογή KapaVita. Κανένα τρίτο API δεν δοκιμάστηκε με προσωπικό κλειδί ή χρησιμοποιήθηκε για αντιγραφή δεδομένων από ιστοσελίδα.

## Απόφαση

Η τρέχουσα καρτέλα εμφανίζει μόνο πραγματικό στίγμα που έλαβε ο δικός μας συλλέκτης και δίνει συνδέσμους προς τους τρίτους παρόχους για αυτοτελή έλεγχο. Δεν κατασκευάζει θέση από πορεία/ταχύτητα ούτε αντιγράφει δεδομένα από HTML άλλων υπηρεσιών. Για πλήρη αυτοματισμό χρειάζεται παρόχος που (α) καλύπτει πραγματικά το συγκεκριμένο MMSI και (β) παραχωρεί ρητά δημόσια ή την επιθυμητή περιορισμένη οικογενειακή προβολή στο συμφωνημένο πακέτο.
