# KV.gr Roadmap

## Task 1 — Foundation

1. Inspect the real Netcup checkout, services, databases, proxy, backups and current release.
2. Create the staging boundary and a project-scoped rollback procedure.
3. Establish the canonical docs and local Git checkpoint on the server.
4. Build the KV shell and navigation while preserving existing KapaVita routes.
5. Add the canonical entity/relationship model and connector contracts.
6. Add deny-by-default users, roles, entity grants, sessions, device records and security events.
7. Add the dashboard layout foundation with a small set of honest static widgets.
8. Test, build, verify the staging URL, record evidence and leave the prior release reversible.

## Later tasks

- Identity hardening: TOTP, passkeys/WebAuthn ceremony, trusted-device risk policy and recovery.
- Entity-specific modules and relationship UX.
- Taxsee/business financial summaries and personal/family money with consented access.
- Investments, watchlists, Copy Trader and MT4/MT5 adapters.
- Google Calendar, Reolink, Shelly and official-source vehicle adapters.
- KV Companion consent-based location with last location and bounded history windows.
- Vault, Projects, Digital Assets, System Health, Attention/Actions and Ask KV.
- V1 hardening, backup/restore drills, security review and eventual private GitHub release.

No later task may bypass the source-of-truth order or the reuse audit.
